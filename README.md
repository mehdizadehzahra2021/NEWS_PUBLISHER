AI News Publisher 🚀

An AI-powered news curation and LinkedIn publishing workflow built with n8n and Ollama.

-Overview
AI News Publisher automates the process of collecting technology news from multiple sources, identifying relevant topics, generating LinkedIn-ready content, and publishing posts.
The workflow combines AI-powered content processing with workflow automation to streamline professional content creation and publishing.

-Features
Automated technology news collection from multiple sources
AI-powered news analysis and topic selection
AI-generated LinkedIn posts
Automated LinkedIn publishing
Local LLM integration using Ollama
Workflow orchestration with n8n

-Tech Stack
n8n — Workflow orchestration and automation
Ollama — Local LLM inference
LinkedIn — Content publishing
LLMs and AI agents — Content analysis and generation

-Workflow
Collect technology news from configured sources.
Process and analyze the collected content using AI.
Identify relevant topics for a professional audience.
Generate LinkedIn post content.
Publish the generated content to LinkedIn.

-Architecture
The workflow uses n8n to coordinate the automation process and Ollama to run language models locally. LinkedIn serves as the publishing destination.
The modular workflow can be adapted to different news sources, language models, and content requirements.


-Getting Started
--Prerequisites
A running n8n instance
Ollama installed and running
A compatible language model configured in Ollama
LinkedIn credentials configured in n8n

-Setup
Clone or download this repository.
Import the workflow JSON file into n8n.
Configure the required Ollama and LinkedIn credentials.
Review the news sources and workflow settings.
Test the workflow before enabling automated publishing.

-Security
Never commit API keys, access tokens, passwords, or private credentials.
Configure credentials securely in n8n.
Review exported workflow files before publishing them publicly.
Replace sensitive account-specific identifiers with placeholders when necessary.
